# Bloom & Bite

## Descripción

Bloom & Bite es un sistema pensado para facilitar la gestión de pedidos y reservas de un restaurante. La idea es tener en un mismo lugar la información de clientes, platos, pedidos y reservas.

## Objetivo

El objetivo es organizar mejor los procesos del restaurante y facilitar la gestión de los pedidos y reservas.

## Problema que resuelve

El sistema busca reducir la desorganización que puede ocurrir cuando los pedidos y las reservas se manejan de forma manual o por diferentes medios.

## Funcionalidades principales

- Gestión de clientes.
- Visualización del menú.
- Gestión de pedidos.
- Gestión de reservas.
- Registro de detalles de los pedidos.
- Consulta del estado del pedido.

## Arquitectura

Se propone una organización separada entre frontend, backend y base de datos. Esto permite que cada parte tenga una función clara y facilita el mantenimiento del sistema.

## Frontend

El frontend será la parte que verá y utilizará el cliente. Allí se mostrarán el menú, los pedidos, las reservas y las demás opciones del sistema.

## Backend

El backend se encargará de procesar las solicitudes, aplicar las reglas del sistema y comunicarse con la base de datos.
